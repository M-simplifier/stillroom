# 休息の景色を選ぶ

**設定 → 休息**には、「旅」「自然」「光と空」の3つの入口があります。「旅」はトロッコと散歩がつながる風景。「自然」に3種類、「光と空」に8種類の、ひとつの場所を眺める景色が並びます。サムネイルを選ぶと、左側に大きなプレビューが現れます。明るさを決めて、下のボタンから休息へ。音楽はそのまま続きます。

## トロッコと散歩がつながる旅

「旅」のサムネイルを選び、「旅を続ける」を押すと、トロッコがゆっくり走り始めます。
初めて選んだ景色の準備には数秒かかります。準備中も音楽は続き、Escで戻れます。

| 操作 | 旅の中で起きること |
| --- | --- |
| Space | トロッコでは停車・出発。徒歩では自動散歩の開始・停止 |
| E | 停車して近くの安全な地面へ降りる。車両のそばでは乗る |
| ↑ / ↓ | トロッコの速さを3段階で変更 |
| WASD | 自分で歩く。自動散歩中に押すと手動に戻る |
| クリック | マウスで見回す操作の開始・解除 |
| ← / → | キーボードで見回す |
| Tab | マウスの視点操作を解除 |
| F1 | 操作説明の表示・非表示 |
| Esc / R / 右上の「作業に戻る」 | 旅を止め、作業画面へ戻る |

橋の上など、安全に降りられない場所では車内に留まります。Spaceで出発して、
次の岸辺を探してください。トロッコは降りた場所で待ち、近くへ戻るとまた乗れます。
橋の上を徒歩で渡る機能や、離れたトロッコを呼び寄せる機能はありません。

作業画面へ戻ると、風景の種・車両の位置・徒歩の位置を保存します。次の休憩や
次回起動後も続きから再開できます。閉じている間に勝手に進むことはありません。
起動直後は作業画面です。別の世界を始めたいときは、設定の「新しい景色」を押します。
この操作は現在の旅を置き換えます。以前の旅へ戻す履歴機能はありません。

旅の保存先は `%APPDATA%/Stillroom/journey.json`。音楽・背景の設定とは別のファイルです。
草原、白樺林、針葉樹林、低木の原野、湿地、砂丘が、起伏や湖と重なって続きます。
すべての土地を保存するのではなく、同じ種から周囲の景色を生成し直しています。

## 「自然」「光と空」は眺めるだけ

背景の空いている場所をクリックするか、休息ボタン、Rキーでも始められます。最初の案内は3秒で消え、その後はマウスを動かしても現れません。時間制限や終了音はありません。

戻る操作は、**クリック / Esc / R**です。作業アプリへ切り替えたときも通常背景へ戻ります。休息中は景色・明るさ・動き・音量・曲・表示設定を変更できません。Space、A、B、数字などを押しても操作は起きません。Windowsのウィンドウを閉じる操作は通常どおり使えます。

## 静かな景色のギャラリーの使い方

1. サムネイルをクリックして、左のプレビューを見ます。
2. 「動き」で、ゆっくり動く状態と静止を比べます。静止にするとプレビューのその瞬間を止め、再び動かすと続きから進みます。
3. 「明るさ」で100%・75%・50%を選びます。作業背景の明るさには影響しません。
4. 「この景色で、ひと息」を押すと、景色が画面いっぱいに広がります。

選択はすぐに保存されます。右上の閉じるボタンでも選んだ内容は残ります。休息に入るたびに景色は先頭の時刻から始まるため、静止設定では同じ絵を比べられます。起動時は通常の作業画面から始まります。

設定は「休息」「作業背景」「音楽・表示」の3ページです。Tab / Shift+Tabで
操作先を選び、EnterまたはSpaceで実行できます。休息中はこれらの操作も無効です。

## 景色の違い

| 景色 | 特徴 |
| --- | --- |
| 白樺の湖畔 | 白樺と草のゆらぎ、湖面に映る明るい空 |
| 山あいの湖 | 針葉樹に囲まれた湖と、遠くに重なる山の稜線 |
| 草原の小川 | 開けた草原を曲がりながら流れる水 |
| 水と光 | 青い水面に重なる波と、空の映り込み |
| 琥珀の海 | 夕暮れの海に伸びる暖かな光 |
| 浅瀬の光 | 澄んだ水を通して見える砂底と、揺れる光の網 |
| 雲の海 | 雲の上から眺める柔らかな陰影 |
| 星の夜 | 位置を変えない星々と、淡い銀河の光 |
| 極夜のオーロラ | 静かな夜空に揺れる光のカーテン |
| 光のヴェール | ほどけるように形を変える光の層 |
| 墨の流れ | 墨と青磁色がゆっくり混ざる模様 |

11種類とも景色の画像素材を使わずに描きます。「自然」は地形や植物もコードから生成し、風や水をシェーダーで動かします。「光と空」の8種類は240秒で連続して巡回します。星の配置は架空で、実際の星座図ではありません。

## 日常の待ち時間で比べる

まず好みの景色を一つ選び、同じ明るさ・同じ音楽で、静止と動く状態を別々の待ち時間に試します。途中で調整したくなったら、いったん戻ってギャラリーを開きます。次に試すときは順番を入れ替えると、最初に見た印象だけで決めにくくなります。

見終わってから、スマホなどへ視線が移らなかったか、目や気持ちの疲れが増えなかったか、作業へ自然に戻れたかを振り返ります。休息中に評価や設定をする必要はありません。これは本人に合う景色を選ぶための比較で、回復効果を実証する試験ではありません。

手法と先行例は[シェーダー表現の調査](shader-research.md)にあります。

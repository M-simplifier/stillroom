# シェーダーで描く休息の景色

調査日: 2026-10-15。Stillroom 0.5の実装判断と、今後試せる表現をまとめています。

水面をきれいにするには、波の数を増やすだけでは足りません。近くでは波の形と空の反射が見え、遠くでは細かい波が混ざって一つの質感になります。水の深さや見る角度も色に影響します。今回はこの組み合わせを改善し、眺め方の異なる8種類の景色をシェーダーで描きました。

## 先行例から取り入れた考え方

| 資料・作品 | 着目した点 | Stillroomでの判断 |

Horizonの[講演資料](https://d3d3g8mu99pzk9.cloudfront.net/AndrewSchneider/The-Real-time-Volumetric-Cloudscapes-of-Horizon-Zero-Dawn.pdf)では、PerlinとWorleyを組み合わせた形状、密度の高さ分布、光の減衰、低解像度での描画をまとめて扱っています。Stillroomの雲はこれより小規模な近似で、同等の雲システムを移植したものではありません。

各資料には公開時点のエンジン仕様が含まれます。比較しているのは描画の考え方で、最新エンジンとの機能・性能比較ではありません。

## 水面をどう変えたか

以前は平面に当たった視線の反射方向を揺らしていました。0.5では、視線と波の高さが交わる場所を求めます。大きな波の高さを7成分、細かな法線を最大13成分で計算します。山と谷の位置が反射に反映され、平らな面に模様が動く状態から奥行きのある波へ変わります。

反射に使う空と画面上の空は同じ関数です。空の青さ、雲の明るさ、夕日の方向が水面にも現れます。垂直に近い角度で見ると水中の色が増え、水平に近い角度では空の反射が増えます。遠くの細波は画素の大きさに合わせて薄め、強い反射は固定露出で抑えます。

浅瀬では屈折した視線を砂底まで進め、距離に応じて光を吸収させます。底に映る光の網は動くセル境界による近似で、集光を光線追跡で解いたものではありません。砕ける波、飛沫、船との接触、周囲の立体物の反射も今回の範囲外です。

FFTは、広い海域や様々な風の条件を扱う段階で有力です。今回の固定カメラでは、解析的な波でも形と照明の改善を直接比較できるため、こちらを選びました。流体シミュレーションの正確さや、ゲームエンジン並みの機能を主張する実装ではありません。

## 実装した8種類

| 景色 | 見るもの | 表現方法 |
| --- | --- | --- |
| 水と光 | 青い波と空の反射 | 変位した水面・解析的な空 |
| 琥珀の海 | 夕暮れの海に伸びる光 | 水面・暖色の空・低い太陽 |
| 浅瀬の光 | 水を通して見える砂底と光の網 | 屈折・吸収・集光模様の近似 |
| 雲の海 | 雲の上から見る立体的な陰影 | 三次元密度の積分・簡易遮光 |
| 星の夜 | 星々と淡い銀河 | 固定配置の星・ノイズの帯 |
| 極夜のオーロラ | 緑の光のカーテンと遠い稜線 | 半透明の光の層 |
| 光のヴェール | ほどけるような柔らかな層 | 滑らかな折り目の重ね合わせ |
| 墨の流れ | 墨と青磁色が混ざる模様 | fBMと座標の変形 |

8種類のシェーダー景色は、画像・動画・ノイズ用テクスチャを入力に使いません。描画結果を拡大するバッファと、起動時に作るサムネイルにはGPUテクスチャを使います。サムネイルと実際の景色は同じ描画処理です。

## 次に試せる表現

以下は未実装の候補です。色違いだけにせず、形と動きの原理で分けています。

| 候補 | 表現方法 | 休息用として確かめたい点 |
| --- | --- | --- |
| 水中から見る光 | 水面法線・体積中の光の減衰 | 光条が視線を引きつけすぎないか |
| 雨の窓 | 雫の形状・背景の屈折 | 雫の出現が気になる出来事にならないか |
| 苔と濡れた石 | 距離関数の形状・粗さ・微細な法線 | 静止していても眺める対象になるか |
| 朝霧の山並み | 層状の地形・距離による霧 | 小さな変化で奥行きを感じられるか |
| 砂丘の風紋 | 高さ場・斜光・風紋の法線 | 遠方の細線がちらつかないか |
| 木漏れ日 | 葉の遮光パターン・ぼかし | 明滅の幅を小さく保てるか |
| 薄氷・曇りガラス | 屈折・粗い反射・内部の模様 | 局所的な光を追い続ける映像にならないか |
| 絹・真珠の光 | 方向による反射色 | 虹色の変化が派手になりすぎないか |
| 溶岩灯のような流れ | メタボール・体積の透過 | 分裂や合体を待ちたくなる強さを調整できるか |
| 干渉模様 | 連続する波の重ね合わせ | 細かい縞や視覚的な振動を避けられるか |

## 描画負荷と使い方

水面などは最大1920×1200、雲海は幅1120を上限にし、窓の縦横比を保って描画します。サムネイルは320×180で一度だけ生成します。設定画面では選択中の景色だけを動かすので、8種類を同時に計算し続けません。

カメラ、露出、星の配置は固定です。音楽連動の明滅や時間に依存する乱数を使いません。静止では景色の時間を止め、音楽の時計だけを進めます。休息中の変更禁止は見た目だけでなく、純粋な状態更新関数でも守ります。

眺め続けたくなる美しさと、作業が再開したら離れられることの両方が大切です。描画テストで分かるのは画面と操作の性質です。本人に合う景色は[使い方と比較方法](rest-mode.md)に沿って、日常の待ち時間で試せます。

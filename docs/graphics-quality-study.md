# Accepted visual experiment — 2026-10-19

The owner accepted a local journey comparison built on Stillroom 0.8.2.
The experiment compared the same seed, camera, semantic clock and geometry
with richer sky, haze, surface lighting, water and shadows. A spatially
supersampled variant added finer edges without temporal history.

The result is now integrated in 0.9. See [graphics quality](graphics-quality.md)
for the shipped controls, budgets, automatic policy and diagnostics. The
interactive `--quality-preview` host belonged to the local experiment and is
not part of the release. Deterministic capture/film diagnostics remain available.

The initial study's three-viewpoint timings were short synchronized captures,
not a moving-world FPS benchmark. Neither that study nor the production checks
establish a therapeutic effect, measured focus improvement or performance on
unobserved hardware.

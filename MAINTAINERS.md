# Maintenance

Maintainer: [M-simplifier](https://github.com/M-simplifier).

Support is best effort, without a service-level commitment. Use issues for bugs
and proposals. Changes use pull requests, required CI and an independent review
context before merging. Releases require audited source, Windows native checks,
third-party notices and a SHA-256 checksum. The executable is unsigned.

Only Windows x64 is supported. Other platform ports, plugin systems, streaming
integrations and medical uses are outside the current release scope.

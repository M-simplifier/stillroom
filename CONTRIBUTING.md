# Contributing

Please open an issue before starting a feature or substantial pull request.
Describe the concrete listening or launch problem first. This is a small,
maintainer-led project; an issue is not a promise of acceptance. Bug reports and
small fixes are welcome. Do not attach recordings you lack rights to redistribute,
personal preferences, or logs containing private paths.

Keep the pure core independent of raylib and filesystem effects. Run the property
suite and relevant native checks. Decoder ownership, dependency and packaging
changes require startup/playback/shutdown checks and a license review. Use Ormolu
0.9.0.0 for Haskell formatting and include regression evidence for fixes.

Source contributions are under MIT. Assets need provenance and compatible
licenses. Claims of therapeutic or cognitive benefit require evidence and review.
